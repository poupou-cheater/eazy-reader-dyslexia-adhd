## WHAT THIS TOOL CAN DO

1. BRAIN-OPTIMIZED TEXT SEGMENTATION
   • Intelligent Parsing: Automatically breaks long, exhausting paragraphs into 
     smaller, bite-sized textual chunks based on a user-defined word limit.
   • Punctuation Awareness: Respects sentence boundaries (. ! ?) to avoid 
     splitting text mid-thought.
   • List & Exercise Protection: Detects structured items automatically 
     (e.g., "1.", "a.", "Exercise 1", "-", "*") and keeps them together inside 
     a unified visual block to preserve layout context.

2. COGNITIVE FOCUS & TRACKING AIDS
   • Visual Fixation (Bionic Reading): Bolds the initial 45% of every single 
     word. This creates strong visual anchors, allowing the eyes to glide across 
     syllables and letting the brain recognize words instantly without getting 
     lost in long strings of letters.
   • Reading Ruler (Blinder Masque): Deploys a full-width focus window that 
     dynamically tracks the vertical movement of your mouse cursor while 
     dimming out the rest of the screen to isolate the exact line being read.

3. ADVANCED TYPOGRAPHY CONFIGURATION
   • Inclusive Fonts: Implements 'OpenDyslexic' (a specialized font featuring 
     heavy bottoms to prevent letters from rotating or flipping in the reader's 
     mind), alongside ultra-legible alternatives like Verdana, Tahoma, Trebuchet MS, 
     and Comic Sans MS.
   • Micro-Adjustments: Provides independent slider controls for:
     - Font size (14px to 80px)
     - Inter-letter spacing (tracking)
     - Inter-word spacing
     - Line height (leading)
   • Global Bold Toggle: Allows forcing the entire document into a bold weight 
     for maximum character definition.

4. ACCESSIBILITY COLOR ARCHITECTURE & CONTRASTS
   • Daltonism Profiles: Pre-configured color contrast matrixing to alleviate 
     color vision deficiencies, featuring:
     - Multicolor Standard Mode
     - Protanopia / Deuteranopia Mode (Red-Green blindness adjustments)
     - Tritanopia Mode (Blue-Yellow blindness adjustments)
     - Monochrome Mode (High-contrast grayscale)
     - Custom Single-Color Mode
   • Zebra Striping (Alternating Fills): Alternates background fills between 
     every text segment using dual color pickers. This prevents the eye from 
     wandering or skipping rows when shifting lines.
   • Seamless Dark Mode: On-the-fly switching between adaptive light and dark 
     themes with intelligent fallback color adjustments.

5. SMART ARCHITECTURE & DATA EXPORTS
   • Zero-Setup Portability: Completely client-side single-page application 
     running inside a single HTML file—requires no server, no installation, 
     and no internet connection after loading.
   • Local Persistence: Automatically saves your text and every single custom 
     slider, checkbox, or color setting directly to the browser (`localStorage`) 
     so it is instantly restored upon reopening.
   • Standalone HTML Export: Packages your tailored text and current layout styles 
     into a separate, lightweight, distribution-ready HTML document.
   • High-Definition Image Export: Translates the active reading zone into a 
     JPEG image via `html2canvas` for offline local viewing.
   • Smart Print/PDF Layer: Features a clean print stylesheet that hides all 
     UI controls and buttons, formatting the text beautifully for paper printing 
     or browser-native PDF saving.
   • Full Native Bilingualism: Instant toggle interface support between French 
     (🇫🇷) and English (🇬🇧).
